# Cirrhosis Prediction Model

A machine learning research project for predicting cirrhosis outcomes using clinical and demographic data.

> WARNING - RESEARCH IN PROGRESS: This repository contains preliminary analyses and modeling work. Results are not final and should not be cited or used for clinical decisions.

## Project Overview

This repository contains a complete pipeline for analyzing cirrhosis patient data and building predictive models. The project uses simulated clinical data (SDV/CTGAN generated) to develop classification models that can predict disease outcomes.

**Dataset Note**: All data in this repository is simulated for research and educational purposes. No real patient information is included.
